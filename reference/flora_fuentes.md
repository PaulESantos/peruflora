# Fuentes integradas por `peruflora`

Devuelve las ediciones consultadas por
[`flora_match()`](https://paulesantos.github.io/peruflora/reference/flora_match.md)
y las versiones instaladas de los paquetes. Describe fuentes locales, no
su vigencia legal.

## Usage

``` r
flora_fuentes()
```

## Value

Tibble con fuente, paquete, edición, referencia y versión instalada.
